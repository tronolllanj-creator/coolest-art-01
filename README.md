# Coolest art: luminous jellyfish over neon city

### Description
This entry features a breathtaking visual of bioluminescent jellyfish floating gracefully above a vibrant, cyberpunk-inspired neon city skyline.

### How it Works
The `main.py` script is extremely lightweight: it simply copies the pre-rendered artwork file (`entry.png`) directly into the designated output directory.

### Requirements & Execution
- **Language:** Python 3.13 (Standard Library only — no external dependencies required).
- **Execution:** Fully deterministic (produces the exact same output every time).
